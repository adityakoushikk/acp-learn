# ACPLearn: A Deep Neural Network to predict anticancer peptides

Try it out: acp-learn.com

Left: Breast Cancer Cells

Right: Breast Cancer Cells treated with an anticancer peptide predicted by deep learning model


Methodology in model/ACPpaper.pdf. Utilized chemical properties of peptides such as AA composition, polarity, etc. for feature engineering to train a DNN, scraped known ACPs as training data from CancerPPD. ACPLearn competes other state of the art methods on a validation dataset ACP740
